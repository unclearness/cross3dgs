# Contributing

Thank you for your interest. Bug reports, questions and feature requests are
welcome as GitHub issues.

Pull requests are not accepted. The software is distributed under the AGPL and
is also offered under commercial terms, so taking outside code would require a
contributor license agreement that is not in place. A fix you describe in an
issue may be re-implemented by the maintainer.

When filing an issue, please include the operating system, the GPU or mobile
device, the Vulkan driver version, the exact command line or app steps, and the
error output or a minimal reproduction.
